# 友だちとの診断結果比較

## 目的

診断結果の共有を受け取ったユーザーが、自分も診断し、2件の結果を8軸で並べて確認できるようにします。

バックエンド、アカウント、データベース、Riot APIは使用しません。比較に必要な情報は既存の回答トークンだけです。

## URL形式

### 比較招待

```text
/compare?base=<回答トークン>
```

招待元の結果タイプ、上位3軸、おすすめロールを表示します。

招待を受けたユーザーは次へ進みます。

```text
/diagnosis?compare=<回答トークン>
```

### 診断完了後の結果確認

```text
/result?r=<自分の回答トークン>&compare=<招待元の回答トークン>
```

通常の結果ページを経由するため、診断完了時の履歴保存が維持されます。

共有URL、履歴URL、結果ページの再読込では新規履歴を作成しない既存仕様も変わりません。

### 完成済み比較

```text
/compare?a=<結果Aの回答トークン>&b=<結果Bの回答トークン>
```

## 比較指標

```text
プレイ傾向の近さ = 100 - 8軸の絶対差平均
```

- 各軸は0〜100
- 同一スコア同士は100
- 全軸が0対100の場合は0
- 小数は四捨五入
- 最終値は0〜100へクランプ

表示ラベル:

| スコア | 表示 |
|---|---|
| 85〜100 | かなり近い |
| 70〜84 | 近い |
| 50〜69 | 一部近い |
| 0〜49 | 対照的 |

この値は次を示しません。

- デュオの相性
- 勝率
- プレイヤースキル
- ランク
- 人間関係
- 実際のチーム構成での強さ

結果タイプ、チャンピオン推薦、ロール一致は比較スコアへ加算しません。指標は8軸差分だけで決まります。

## 表示内容

完成済み比較ページでは次を表示します。

- プレイ傾向の近さ
- 比較ラベル
- 結果A・結果Bのタイプ
- 両者のおすすめロール
- 8軸すべてのスコアと差分
- 差が小さい上位3軸
- 差が大きい上位3軸
- おすすめロールの共通部分

同点時は`AXIS_KEYS`の既存順序を利用し、表示順が実行ごとに変わらないようにします。

## URL検証

比較ページは次のどちらかだけを受け付けます。

- `base`が1件だけ
- `a`と`b`が各1件だけ

以下は比較対象として受け付けません。

- パラメータ不足
- 複数の`base`、`a`、`b`
- `extra`などの追加パラメータ
- 不正な回答バージョン
- 回答数不一致
- -2〜2以外の回答
- チェックサム不一致
- 既存回答バリデーションエラー

診断ページの比較モードは、`compare`が1件だけで追加パラメータがない場合に有効になります。

結果ページの比較継続は、`r`と`compare`が各1件だけで、`r`が表示中の有効な回答トークンと一致する場合に有効になります。

## プライバシー

比較URLには2件の回答トークンが含まれます。

回答トークンには次を含みません。

- 氏名
- メールアドレス
- Riot ID
- ランク
- 戦績
- IPアドレス
- Cookie

比較結果・比較履歴はサーバーへ保存しません。比較URLを知っている人は結果を再表示できるため、公開範囲は利用者自身で判断します。

Analyticsへ回答トークン、比較URL、8軸スコアは送信しません。

## 検索エンジン

`/compare`は次を設定します。

- `noindex`
- `nofollow`
- robots.txtの`Disallow`
- sitemapへ追加しない

## 共有操作

比較招待・比較結果で次を利用できます。

- Web Share API
- URLコピー
- X共有

Web Share APIに対応しないブラウザでは、URLコピーとX共有を利用できます。共有ダイアログのキャンセルはエラー扱いしません。

## Analyticsイベント

- `comparison_invite_created`
- `comparison_diagnosis_started`
- `comparison_completed`
- `comparison_link_copied`
- `comparison_shared`
- `comparison_share_failed`
- `comparison_invite_restarted`

イベントには画面種別、共有チャネルなどの固定値だけを設定します。

## 確認方法

```bash
bash scripts/check-comparison-files.sh
npm run lint
npm run test
npm run build
npm run smoke:standalone
```

手動確認:

1. 診断結果ページの「友だちと比較」を開く
2. 招待元のタイプ・上位3軸・ロールを確認する
3. 招待URLをコピー・共有する
4. 招待URLから診断へ進む
5. 診断ページに比較モード表示があることを確認する
6. 診断完了後に通常結果と履歴保存を確認する
7. 「友だちとの比較結果を見る」を開く
8. 8軸、近い軸、違いが大きい軸、共通ロールを確認する
9. 比較URLをコピー・共有する
10. 不正、複数、追加パラメータで比較できないことを確認する

## 対象外

- ユーザー名入力
- 比較履歴の保存
- 3人以上の比較
- 勝率・戦績・ランク連携
- Riot API連携
- 人間関係やデュオ相性の判定
- 比較専用OGP画像
